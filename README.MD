## GastosApp
Una aplicacion para android escrita en kotlin que permite el tracking de ingresos y gastos del usuario, permitiendo clasificarlos mediante
categorias modificables y visualizarlos respecto a objetivos declarables mediante metas u objetivos de ahorro.
